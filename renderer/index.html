Do it for me: desktop app only

This is a placeholder. A web page cannot see your other windows or type into them, so this feature lives in the Mathbench app for Windows.

In the app, press Ctrl + Alt + P on a worksheet or quiz and type what to do, such as "do 3", "all" or "1-4 as decimals". Mathbench reads the screen, solves each problem and types every answer into its box.

Download the Mathbench app to use this feature.
