# Mathbench

Equation solver, graphing calculator and maths reader for Windows. Everything runs on your computer: no account, no key, no internet needed.

## Download

**[Download the latest installer](https://github.com/meowskers101/mathbench/releases/latest)** (Mathbench Setup .exe, Windows 10 or 11, 64-bit).

1. Run the installer, choose a folder and click Install. It adds Mathbench to the Start menu and the desktop.
2. If Windows says "Windows protected your PC" (the installer is not code-signed), click **More info**, then **Run anyway**.

Mathbench then lives in the system tray (bottom-right, near the clock). Right-click the tray icon for Settings or Quit.

## What it does

- **Solver**: type or paste an equation, expression, system of equations or function problem and get the answer with the working.
- **Graphing calculator**: plot functions, equations, inequalities, points, polar and parametric curves.
- **Read from a picture**: capture part of the screen (Ctrl + Alt + M) or open a picture, and Formula AI reads the maths for you, including stacked fractions, roots, powers and several lines.
- **Do it for me** (Ctrl + Alt + P): Mathbench finds the numbered problems on the page in front of you, solves them and types each answer into its box (in OneNote, beside the problem). Type what to do, such as "all", "do 3" or "1-4 as decimals".
  - **Words**: without words, less, with or more words.
  - **Work**: off, a few steps, some steps or all steps (every small step, with a check).

## Good to know

- Check what Mathbench read before trusting an answer.
- Some schools and test sites do not allow tools that fill in answers. Follow the rules of the site and class you are using it for.

## Uninstall

Windows Settings > Apps > Installed apps > Mathbench > Uninstall.
